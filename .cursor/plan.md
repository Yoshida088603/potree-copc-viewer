# Potree COPC Viewer 拡張計画（2025/06 アップデート）

## 目的
- 複数のCOPC ID（例: 104811, 104815, 104819 など）を一度に入力し、まとめて処理・表示できるようにする。
- ID入力ボックスを画面右上から左下に移動し、UIの使い勝手を向上させる。
- 使い方ガイドのURLを明示的にUIに表示する。

## 実装手順
1. **複数ID入力対応**
    - ID入力欄でカンマ区切り、または改行区切りで複数IDを受け付けるようにする。
    - 入力値をパースし、各IDごとにCOPCファイルのURLを生成する。
    - 複数のCOPCを同時にPotree上で表示できるようにする。
2. **ID入力ボックスのUI位置変更**
    - 既存のID入力ボックスを右上から右下にレイアウト変更する。
    - スタイルシート（CSS）やHTMLの該当箇所を修正する。
3. **使い方ガイドのリンク追加**
    - 画面右上に「使い方」へのリンク（[使い方](https://note.com/yoshida_shirou/n/n61f55a71a56d)）を分かりやすく表示する。
    - ユーザーが迷わずアクセスできるよう、リンクの配置や文言を工夫する。
4. **動作確認・共有**
    - 複数ID入力時の動作、UI位置変更、使い方リンクの表示を確認する。
    - 共有URLやGitHub Pagesでの動作も再度検証する。

## 備考
- 複数ID入力時、無効なIDや重複IDの扱いも考慮する。
- 使い方ガイドの内容は随時アップデートする。
